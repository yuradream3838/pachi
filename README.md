# マイジャグラーV 設定推測ツール

マイジャグラーVの設定推測と、収支・交通費・拘束時間・店情報を記録するツール。
HTML1枚で動き、記録はすべて端末内（ブラウザの localStorage）に保存されます。
サーバーへの送信は一切ありません。

## 使う

公開URL（GitHub Pages）を開き、ホーム画面に追加するとアプリとして使えます。

- iPhone / iPad … Safariで開く → 共有ボタン → 「ホーム画面に追加」
- Android … Chromeで開く → 画面上部の案内、またはメニューの「アプリをインストール」

追加すると、アイコンから直接開けて、**圏外でも動きます**。

## 公開URLを用意する（初回のみ）

GitHub Pages を有効にします。

1. リポジトリの **Settings** → 左メニューの **Pages**
2. **Source** を `Deploy from a branch`
3. **Branch** を `main` ／ フォルダを `/ (root)` にして **Save**
4. 1〜2分待つと `https://<ユーザー名>.github.io/pachi/` が公開される

## データの持ち運び

記録は**開いたURLごと・ブラウザごとに別々**に保存されます。
スマホとPCの間で同期はしません。開き方を変えると前の記録は表示されません
（消えてはいませんが、元のURLに戻らないと出てきません）。

移すときや機種変更のときは、③の下部から：

1. 移す前の環境で「**書き出す（バックアップ）**」→ JSONを保存
2. 移した先で「**読み込む（復元）**」→ そのJSONを選ぶ
3. 「追加」か「すべて置き換える」を選ぶ

ブラウザの閲覧データ削除や、iOSで長期間開かなかった場合に消えることがあります。
ときどき書き出しておくと安全です。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | 本体（画面・計算・保存のすべて） |
| `manifest.json` | アプリ名・アイコン・起動方法 |
| `sw.js` | オフライン用のキャッシュ。更新時は `CACHE` の版を上げる |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アイコン |

## 注意

パチスロは長期的には店側が利益を出す設計です。
このツールは不利を減らす立ち回りの補助であり、勝ちを保証するものではありません。
